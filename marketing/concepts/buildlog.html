A TypeScript framework with Rails' conventions. Not finished — but not vapour either.

Typeway is thin glue over Bun, Elysia, Vite and TypeBox, unified by one set of conventions, one docs format and one CLI. There is no launch date. There is this log, which is the honest version of a roadmap: what shipped, when, and what it cost.

Shipped One request scope for the whole stack

An AsyncLocalStorage context established by a fetch wrapper around listen(), so Elysia routes, TanStack SSR and server functions all resolve the same getDb() and share one transaction() per HTTP request. Drizzle over Bun's SQLite, with a notes API and page dogfooding it.

3 Aug

Shipped Production stops going through the bridge

The built SSR handler is fetch-native, so production mounts it directly on Elysia (.mount(), ~0.4 µs) instead of paying for a Connect round-trip, and the client build is registered as static routes at boot. The bridge is now what it should always have been: a dev-mode component for Vite.

2 Aug

Shipped SSG, SSR and SPA — one page each

Three rendering strategies in one app, each turned on by a single line, each rendering the same loader so the difference is visible on a hard reload. The prerendered page is served in production by a static route at its clean URL and never reaches the SSR handler.

31 Jul

Fixed Request bodies drain lazily

Building the bridge's request used to read the web stream up front, which locked it and broke every POST that fell through to SSR with Body already used — server functions, form actions, uploads. Now the wrapper is lazy. 

cost of laziness      +1–2 µs/req   (inside run-to-run spread)
Readable.from(gen)    ~2.4x slower  rejected
manual pull loop      ~2.4x slower  rejected

31 Jul

Shipped Paired A/B benchmarks

Not "Typeway does N req/s" — every arm is measured back to back against its own baseline on one machine, interleaved round by round, median by RPS. The question was what the glue costs.

scenarioratioΔ µs/req
registered route, bridge mounted0.985×+0.2
SSR via connect() fallback1.010×−2.0
static asset, prod path0.995×+0.2
bare bridge round-trip (GET)0.485×+10.6

The last row is the honest one: a bridge hop costs ~10 µs, which is most of a request that does nothing and none of a request that does something.

The first real piece: run Connect/Express middleware inside an Elysia app, mounted as a wildcard route so registered routes never touch it.
