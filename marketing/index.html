The core stack

          
We didn't write a runtime. We picked the winners.

          

            Every piece is something you'd choose on its own merit. Typeway's job is the part nobody wants to
            do twice: making them agree on conventions, types and a project layout.
          


          

            

              
Bun 1.4

              

                Runtime, package manager, test runner and bundler — plus built-in SQLite, Postgres and S3
                clients, and --compile for single-binary deploys.
              

            

            

              
Elysia 2.0

              

                The HTTP host. End-to-end type safety from route to client, a real plugin system, and Eden for
                a fully typed API client with no codegen step.
              

            

            

              
Vite 8

              

                The frontend, hosted under Elysia through a Connect bridge — so dev is one process
                with HMR, and prod is a built handler mounted on the same router.
              

            

            

              
TypeBox

              

                One validation story everywhere: request schemas, typed environment and config, model
                validation. Types you declare once and infer from forever.
              

            

          

        

      


      
      

        

          
Not a landing page for an idea

          
The hard part already runs.

          

            Hosting a modern frontend inside a typed API server, in one process, without either side knowing
            about the other — that was the risky piece. It's built, dogfooded and benchmarked.
          


          

            
    
              
  • 
                
                
    
                  @typeway/connect — run any Connect/Express middleware under Elysia. Raw
                  streamed bodies, streaming responses, Set-Cookie fidelity, zero runtime deps.
                
    
              
    • 
              
  • 
                
                
    
                  One process in dev. Vite in middleware mode plus SSR in the fallback —
                  your API routes bypass the bridge entirely and pay nothing for it.
                
    
              
    • 
              
  • 
                
                
    
                  SSG, SSR and SPA side by side in one app, each a one-line decision, all
                  served by the same router in production.
                
    
              
    • 
              
  • 
                
                
    
                  Proven, not asserted. A kitchen-sink fixture app exercises streaming SSR,
                  server functions, redirects, cookies, multipart, SSE and binary assets — in dev
                  and prod, on every commit.
                
    
              
    • 
              
  • 
                
                
    
                  Paired A/B benchmarks against clean Elysia and standalone TanStack, so
                  every performance claim here is a measured ratio, not a vibe.

                server.dev.ts
              

              
import { connect } from "@typeway/connect";
import { Elysia } from "elysia";
import { createServer } from "vite";

const vite = await createServer({
  server: { middlewareMode: true },
});

new Elysia()
  // typed routes — never touch the bridge
  .get("/api/hello", () => ({ ok: true }))
  // everything else: Vite, then SSR
  .use(connect(vite.middlewares, { fallback: ssr }))
  .listen(3000);

            

          

        

      


      
      

        

          

            
The part Rails never had to solve

            
Written for humans. And for the agents they work with.

            

              Half the code in your repo next year will be written by something that has never read your
              README. Conventions that are deterministic and greppable aren't a nice-to-have any more —
              they're the interface.
            


            

              

                
Predictable by design

                

                  One canonical place for every concern. An agent that has seen one Typeway app can navigate
                  every Typeway app — no exploration budget spent on your folder taste.
                

              

              

                
Docs in agent formats

                

                  Skills, AGENTS.md and llms.txt ship as first-class artifacts, not
                  as an afterthought scraped out of a docs site.
                

              

              

                
Generators teach

                

                  Every generator installs the knowledge to use what it just wrote, next to the code it wrote.
                  Context arrives with the feature.
                

              

            

          

        

      


      
      

        

          
Roadmap

          
What's coming under the umbrella.

          

            Each of these is an integration with conventions, docs and generators around it — never a wrapper
            you have to fight later. If you outgrow one, you eject to the library underneath.
          


          

            

              
Connect bridge
Shipped

              
Any Connect/Express middleware under Elysia. Streaming both ways, zero runtime deps.

            

            

              
Full-stack dev server
Shipped

              
Vite + SSR + typed API in one process, with HMR; a static-manifest fast path in prod.

            

            

              
Rendering modes
Shipped

              
SSG, SSR and SPA in the same app, each turned on by a single line.

            

            

              
Models
Building

              
Drizzle with conventions for structure, relations, migrations, seeds and factories.

            

            

              
Request context
Building

              
One AsyncLocalStorage scope per request, shared by API routes, SSR and server functions.

            

            

              
The CLI
Building

              
new, generate, add, db, console — scaffolding with the docs attached.

            

            

              
Auth
Planned

              
typeway add auth — better-auth, wired, documented and yours to modify.

            

            

              
Background jobs
Planned

              
A Postgres-backed queue by default. No Redis until you actually need Redis.

            

            

              
Mailers
Planned

              
react-email templates, pluggable adapters, previews in development.

            

            

              
Realtime
Planned

              
Elysia websockets with channel conventions instead of a bespoke event soup.

            

            

              
Storage & caching
Planned

              
A thin layer over Bun's native S3 client; database-backed cache, Redis optional.

            

            

              
Testing
Planned

              
bun test, factories, and request specs through Eden — type-checked against your routes.

            

            

              
Security defaults
Planned

              
CORS, secure headers and rate limiting on from the first request, not from the first incident.

            

            

              
Observability
Planned

              
Structured logging and OpenTelemetry as a convention rather than a weekend project.

            

            

              
Deploy
Planned

              
One binary via bun --compile. Copy it to a box and run it.
